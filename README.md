## Selected work

### AI & intelligent systems

**[Dendritic Memory Systems](https://github.com/deadSwank001/DendriticMemorySystems)**  
A research prototype exploring persistent, provenance-aware memory and associative retrieval for language models.

**[Nexus MCP](https://github.com/deadSwank001/Nexus-MCP-2.0)**  
Project context management for AI coding assistants, with SQLite, semantic search, and optional Ollama-powered features.

**[Bio-CNN](https://github.com/deadSwank001/Bio-CNN)**  
An exploration of convolutional networks, regression, and clustering for genomic variant identification and sample analysis.

### Applications & experimentation

**[Agro-Onyx](https://github.com/deadSwank001/Agro-Onyx_Frontend)**  
An aggregator and swap project spanning a [frontend](https://github.com/deadSwank001/Agro-Onyx_Frontend), [backend](https://github.com/deadSwank001/Agro-Onyx_Backend), and [transaction engine](https://github.com/deadSwank001/Agro-Onyx_TransactionEngine).

**[SHENZEN I/O Workshop Component Analysis](https://github.com/deadSwank001/SHENZEN-I-O-Workshop-Component-Analysis-App)**  
A TypeScript application that explains workshop components and their technical details.

**[Langton's Ant in Blender](https://github.com/deadSwank001/Langton-s_Ant_in_Bpy)**  
A Python and Blender study of cellular automata inspired by The Algorithms project.
